# Development Environment Setup

This manual describes the strict pipeline to initialize this ecosystem's open-source architecture. Built under the **Jamstack** philosophy, it requires zero local database overhead.

## 🛠️ Infrastructure Prerequisites
- **Runtime:** Node.js v24 or higher
- **Package Manager:** NPM v11 or higher
- **Framework:** Astro v7 (Content Layer API)

## 🚀 3-Step Deployment (Bash Console)

To safely clone and audit this project, execute the following command sequence in your terminal:

1. **Clone the remote repository:**
   ```bash
   git clone https://github.com
   ```

2. **Install isolated dependencies:**
   ```bash
   npm install
   ```

3. **Launch the cloud development server:**
   ```bash
   npm run dev
   ```

The system will compile static assets in real time and expose a secure local port (usually `http://localhost:4321/`) to audit the Bento Grid components.
